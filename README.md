# RONIT VISUALS — Video Portfolio Website

A minimalist, high-impact dark portfolio website inspired by the Kern Studio aesthetic with Google Drive embedded video streams.

## 🚀 How to Host on GitHub Pages (2 Minutes)

### Step 1: Create a GitHub Repository
1. Go to [GitHub](https://github.com) and click **"New repository"**.
2. Name it `my-portfolio` (or `your-username.github.io` for a root domain).
3. Set visibility to **Public**.
4. Click **Create repository**.

### Step 2: Upload the Files
Upload the following files to your new repository:
- `index.html`
- `style.css`
- `logo.png` (or your logo file)
- `README.md`

### Step 3: Turn on GitHub Pages
1. In your GitHub repository, click on **Settings** (top right tab).
2. On the left sidebar menu, click **Pages**.
3. Under **"Build and deployment"** > **"Source"**, select **"Deploy from a branch"**.
4. Set Branch to **`main`** and folder to **`/(root)`**.
5. Click **Save**.

🎉 Within 30 seconds, your site will be live at:
`https://<your-username>.github.io/my-portfolio/`

## 📹 How to Add & Embed Google Drive Videos

1. **Share your video file in Google Drive**:
   - Right-click your video file in Google Drive.
   - Click **Share** > **Share**.
   - Under *General access*, select **"Anyone with the link"** with role set to **Viewer**.
2. **Copy the Link or File ID**:
   - The link looks like: `https://drive.google.com/file/d/1ABCXYZ_987654321/view?usp=sharing`
   - The File ID is: `1ABCXYZ_987654321`
3. **Embed in your HTML**:
   - Use the preview format: `https://drive.google.com/file/d/YOUR_FILE_ID/preview`
   - This automatically enables smooth streaming and browser video playback without requiring raw storage servers!
